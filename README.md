# Chaos Conductor feedback

Public issue tracker for [Chaos Conductor](https://jacobarose.com/demos/chaos-conductor/), a browser instrument with an XY pad, loops, drums, effects and MIDI output, and for its [guide](https://jacobarose.com/demos/chaos-conductor/docs/).

The app's source code lives in a separate repository. This one holds only issue forms.

- **Something wrong or unclear in the guide?** Use the "Report a problem with this page" link at the bottom of any guide page, or open a [guide problem](../../issues/new?template=docs-problem.yml).
- **A bug in the app?** Open an [app bug](../../issues/new?template=app-bug.yml).

Issues here are public. Please don't include personal information.
